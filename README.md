# SVG Flowchart — 零依赖内联流程图

一个关于"用内联 SVG 把流程图直接嵌进 HTML 方案文档"的规范和工具集。

## 核心价值：零依赖嵌入

**流程图是`内联 SVG`，不是图片、不是外链。** 这带来几个实打实的好处：

- **零依赖**：不引任何 JS/CSS 库、不加载网络资源，`<svg>` 直接写进 HTML
- **即开即看**：单文件 HTML 浏览器双击就能打开，离线可用
- **清晰锐利**：矢量放大不糊，打印、投屏、缩放都无损
- **可维护**：每个节点坐标明文可见，改布局就是改几个数字
- **可校验**：能被脚本自动检查（斜线、对齐、重叠），这是图片/外链流程图做不到的

> 适用：自包含单 HTML 方案文档、技术说明书、汇报 PPT、需要精确排版的对齐流程。
> 如果只是放 Markdown/GitHub README、且流程简单，Mermaid 更合适（语法简单、可编辑）。

## 黄金规则（画得干净的核心）

### R1. 连线全正交
禁止对角线。每根线只能是水平（H）或垂直（V）段。
只有"指向菱形"的短斜线可以豁免（菱形本身是斜的），但能垂直就垂直。

### R2. 主链中心对齐 → 连线纯垂直（最重要）
一条逻辑链上的节点，**垂直中心 x 全部对齐**。
对齐后块→块、块→菱形就是**一根纯垂直竖线，零折弯**。
> 要线直，靠的是**微调块的位置去对齐**，而不是**加折线去绕**。这是避免"折线乱翘"的根本方法。

### R3. 单折弯优先
分支（如菱形分流）才允许拐弯，且每个分支**最多 1 个拐点**（L 形：水平引出→垂直进框），禁止 S 形多折。

### R4. 箭头必须对准目标
指向方框 → 箭头终点 = 方框**顶部中心**；指向菱形 → 箭头终点 = 菱形**上顶点**。差几个像素都算没对准。

### R5. 菱形是"夹心饼干"，别单独挪
菱形上下都连着节点，一挪就破坏上下对齐。**要挪就挪菱形上方的块**，让它中心 = 菱形顶点的 x。

### R6. 方块间距均匀、不重叠
并排分支方框之间留 ≥20px 间隙，绝不允许重叠。方框要够大、容纳文本不贴边。

### R7. 尽量少用图例
已用颜色区分角色的流程，别加图例——图例里的小图形最容易画歪。

## 如何用

1. **从模板起步**（`templates/`）：
   - `chain-vertical.svg` — 纯垂直主链（最简单）
   - `decision-branch.svg` — 判断菱形 + 三分支
   - `h-v-ortho.svg` — 完整正交流程图
2. **内联进 HTML**：把 `<svg>` 直接粘进单 HTML，零外部依赖。
3. **自动校验**（可选，强烈建议）：
   ```bash
   python3 scripts/validate.py your-file.html
   # ✓ 全部通过 / ❌ 逐条列出 violate(R1对角线/R4箭头未对准/R6方块重叠)
   ```
   校验工具能在交付前抓出斜线、箭头偏、框重叠这类肉眼难发现的细节问题。
4. **提取坐标核对**（可选）：
   ```bash
   python3 scripts/extract.py your-file.html
   # 打印每个框的中心 x 和菱形上顶点, 便于核对对齐
   ```

## 目录结构

```
svg-flowchart-skill/
├── README.md                 # 项目说明(本文件)
├── templates/                # 三个起步模板
│   ├── chain-vertical.svg
│   ├── decision-branch.svg
│   └── h-v-ortho.svg
└── scripts/
    ├── validate.py           # 自动校验: 斜线/对齐/重叠
    └── extract.py            # 提取解析 SVG 节点坐标
```

## 校验指标（validate.py）

| 检查 | 阈值 | 说明 |
|------|------|------|
| 斜线 | = 0 | 不允许对角线（菱形短斜线除外） |
| 箭头对准 | 误差 ≤ 2px | 方框顶部中心 / 菱形上顶点 |
| 方块重叠 | = 0 | 并排框间距 ≥ 20px |
| HTML 完整性 | 无未闭合标签 | HTMLParser 校验 |

## 常见坑

1. "为对准顶点把直线改成斜线" ❌ → 挪块对齐，让线保持垂直 ✅
2. "块和菱形错位就加三段折线绕" ❌ → 微调块中心 = 菱形顶点 x，线自然就直 ✅
3. 菱形是夹心饼干别单挪 ✅
4. 图例小菱形画不齐 → 干脆去掉 ✅
